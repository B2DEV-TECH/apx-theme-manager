# APEX Theme Manager v0.1.0-beta

An independent B2DEV TECH community beta for application-definition snapshots,
semantic layout comparison and controlled recovery of a tested scalar subset.

The native APEX manager implements **Compare → Review → Preview → Backup →
Apply → Verify**, with selected/all-eligible repair, a separately authorized full
definition restore, downloadable artifacts and operation history.

## Installation

Download and extract `APEX-Theme-Manager-v0.1.0-beta.zip`. Start SQL*Plus from its
repository root and follow [the installation guide](https://github.com/B2DEV-TECH/apx-theme-manager/blob/v0.1.0-beta/docs/installation/README.md).
The bundle includes database scripts, the native manager, the original sample,
documentation and optional development tests. Destination schema/workspace/app
IDs are chosen explicitly. Recovery starts disabled; no powerful privileges are
silently granted. Node.js is unnecessary at runtime.

## Tested scope

- Exact **APEX 26.2.0**, Oracle AI Database 26ai Free **23.26.3.0.0** on Windows.
  APEX 24.2 and other releases remain untested.
- Recognized explicit grid/span/column and supported row/field scalars; exact
  selection, fresh-state checks, expiring actor-bound requests and verified backup.
- Template references/options, display points and theme defaults are
  detection-only. Inherited theme bodies are absent from the actual lab export;
  no live cross-theme name/class equivalence is certified.
- Arbitrary shared/interleaved item/BODY-button rows are rejected. Only known
  trailing new-row/new-column BODY buttons pass this conservative beta boundary.

Tests exercised selected/all-eligible recovery, full restore, stale/replayed

## Authority and limits

The manager requests workspace-wide **Modify Other Applications** authority.
Install only in a dedicated, trusted development workspace. Server-side roles,
target registration and live identity checks constrain project operations; the
declared APEX authority itself is broad. Full restore requires matching exported
ACL assignment state and a separate typed confirmation.

An application definition is not a runtime-data or external-dependency backup.
Application import can partially commit; there is no atomic rollback guarantee.
Oracle's generated SQL warns that modified exports are unsupported. Public API
usage does not create an Oracle support contract for this experimental transformer.
Large real applications, saved-report/notification/translation preservation
scenarios and interruption at every import phase remain untested.
